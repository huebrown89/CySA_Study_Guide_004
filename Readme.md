# CySA+ CS0-004 Study Guide

An interactive practice quiz for the CompTIA CySA+ (CS0-004) exam. Each question comes with an explanation, and you can choose how many questions to take and which study mode to use.

## Use it

Open the live version here: **https://huebrown89.github.io/CySA_Study_Guide_004/**

The guide is one self-contained file (`index.html`), so you can also download it and open it in any browser.

Looking for the CS0-003 version? It's at **https://huebrown89.github.io/CySA_Study_Guide/**
